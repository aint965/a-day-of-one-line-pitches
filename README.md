## The pitch

> Just describe the app idea you've been carrying around in plain words, and an AI agent will build you a real, working version on make.fun — no code, nothing to install, and if you don't love it, you've lost nothing but a few minutes.

One sentence, 233 characters, written to convince a friend who has never
coded to let an AI agent build their first app idea on make.fun.

## How it works

`main.py` (Python 3, no dependencies) writes exactly that sentence to
`/output/entry.txt` — UTF-8, no trailing newline — after asserting it is
1–240 characters, a single sentence, and a single line.

```sh
python3 main.py
```
